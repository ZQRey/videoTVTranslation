# 📱 StreamClient TV — Android TV & Mobile Client (`android/`)

Нативное клиентское приложение на **Kotlin** для устройств под управлением **Android TV** (умные телевизоры, медиаприставки, проекторы, инфо-панели) и стандартных Android-устройств (планшеты, смартфоны).

Приложение разработано для непрерывного (24/7) фонового воспроизведения живого видеопотока RTSP или HLS с центрального медиасервера трансляции (`videoTVTranslation`).

## 🚀 Ключевые возможности

1. **AndroidX Media3 ExoPlayer 1.3.1**:
   - **Принудительный RTSP over TCP**: директива `RtspMediaSource.Factory().setForceUseRtpTcp(true)` полностью устраняет артефакты ("рассыпание" картинки на квадраты) и дропы кадров при передаче RTP через беспроводные сети Wi-Fi на бюджетных ТВ-приставках.
   - **Поддержка HLS (HTTP Live Streaming)**: возможность быстрого переключения на HLS-плейлисты (`HlsMediaSource.Factory`) через порт 8888.
   - **Оптимизация буферизации под маломощные чипы**: индивидуальный `DefaultLoadControl` (1000 мс предбуферизация и 500 мс старт) минимизирует задержку "живого" эфира.
2. **Отказоустойчивый цикл автопереподключения (Reconnect Loop)**:
   - При кратковременном обрыве сети или перезапуске сервера вещания приложение не зависает и не завершает работу аварийно.
   - На экране отображается ненавязчивая карточка с обратным отсчетом времени до повторного коннекта («Повторное подключение через 4 сек…»).
   - Переподключение продолжается автоматически в фоне вплоть до успешного перехода в статус `STATE_READY`.
3. **Полная интеграция с ТВ-пультами ДУ (D-Pad Navigation)**:
   - Полноценная поддержка спецификации Leanback без искусственной блокировки мобильных устройств (`uses-feature android.software.leanback required="false"`).
   - Четкая индикация фокуса: анимированное масштабирование элементов `FocusableConstraintLayout` (1.03x) и яркие контрастные контуры кнопок.
4. **Умный перехват кнопки «Назад» (Back Interception)**:
   - Во время трансляции случайное нажатие кнопки «Назад» на пульте **не закрывает** приложение, а ставит воспроизведение на паузу и открывает окно настроек подключения к серверу.
   - Повторное нажатие кнопки «Назад» закрывает настройки и мгновенно возобновляет трансляцию.
5. **Полноэкранный Immersive Mode**:
   - Полное сокрытие системных панелей Status Bar и Navigation Bar.
   - Принудительная блокировка засыпания экрана (`FLAG_KEEP_SCREEN_ON`).
6. **AndroidX DataStore Preferences**:
   - Быстрое и асинхронное персистентное сохранение параметров подключения (IP сервера, порт, протокол RTSP/HLS, путь потока).

## ⚙️ Системные требования

- **Java Development Kit (JDK)**: версия **17** или **21**.
- **Android SDK**:
  - `compileSdk`: **34** (Android 14)
  - `minSdk`: **21** (Android 5.0 Lollipop — совместимо с подавляющим большинством ТВ-приставок)
  - `targetSdk`: **34**
- **Android Debug Bridge (ADB)**: входит в состав Android SDK Platform-Tools.
- **Android Studio** (Hedgehog 2023.1.1 / Iguana / Jellyfish) — рекомендуется для визуальной сборки.

## 📦 Настройка окружения разработчика

1. Убедитесь, что переменная `JAVA_HOME` указывает на JDK 17+:
   ```bash
   java -version
   ```
2. Проверьте путь к Android SDK в файле `android/local.properties`:
   ```properties
   sdk.dir=C\:\\Users\\<USERNAME>\\AppData\\Local\\Android\\Sdk
   ```
   *(На Linux/macOS путь обычно: `/home/<user>/Android/Sdk` или `/Users/<user>/Library/Android/sdk`)*.

## 🔨 Компиляция и сборка APK

### Способ 1: Сборка через Gradle Wrapper из консоли

Перейдите в директорию `android/`:
```bash
cd android
```

#### Сборка отладочной версии (Debug APK):
- **Windows**:
  ```powershell
  .\gradlew.bat assembleDebug
  ```
  *(или `gradle assembleDebug`, если Gradle установлен глобально)*
- **Linux / macOS**:
  ```bash
  ./gradlew assembleDebug
  ```

Готовый файл APK сформируется по пути:
👉 `app/build/outputs/apk/debug/app-debug.apk`

#### Сборка релизной оптимизированной версии (Release APK):
```bash
./gradlew assembleRelease
```
Готовый файл APK:
👉 `app/build/outputs/apk/release/app-release-unsigned.apk`

#### Полная очистка сборочных кэшей:
```bash
./gradlew clean
```

---

### Способ 2: Сборка через Android Studio (GUI)

1. Запустите Android Studio.
2. Выберите **File** -> **Open...** и укажите папку `android/`.
3. Дождитесь завершения автоматической синхронизации проекта (**Gradle Sync**).
4. В верхнем меню выберите: **Build** -> **Build Bundle(s) / APK(s)** -> **Build APK(s)**.
5. После сборки появится уведомление с ссылкой **locate** на готовый `app-debug.apk`.

## 📲 Установка на Android TV через ADB

### Шаг 1. Подготовка телевизора / ТВ-приставки
1. Откройте **Настройки** Android TV -> **Об устройстве** (Device Preferences).
2. Найдите пункт **Сборка** (Build) и нажмите на него пультом **7 раз подряд**, пока не появится надпись *"Вы стали разработчиком!"*.
3. Вернитесь назад в **Для разработчиков** (Developer Options).
4. Включите:
   - **Отладка по USB** (USB Debugging).
   - **Отладка по сети** (Network Debugging), если доступно на вашей модели.

### Шаг 2. Подключение по Wi-Fi
Узнайте IP-адрес приставки в меню сети (например, `192.168.1.150`). На компьютере выполните:
```bash
adb connect 192.168.1.150:5555
```
> На экране телевизора появится диалог подтверждения отпечатка ключа RSA — выберите **"Всегда разрешать с этого компьютера"** и нажмите **OK**.

Проверьте статус подключения:
```bash
adb devices
```
*(Статус устройства должен быть `device`, а не `unauthorized`).*

### Шаг 3. Инсталляция APK-файла
```bash
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

## 🎮 Запуск и управление с пульта ДУ

### Запуск приложения:
- **Через меню ТВ**: Найдите иконку **StreamClient TV** на главном экране Android TV (в ленте каналов / приложений).
- **Либо через команду ADB**:
  ```bash
  adb shell am start -n com.example.streamclient/.ui.MainActivity
  ```

### Управление пультом ДУ:
| Кнопка пульта | Действие в приложении |
|---|---|
| **D-Pad Вверх / Вниз / Влево / Вправо** | Перемещение фокуса между полями ввода и кнопками диалога настроек. Фокусируемый элемент плавно увеличивается (1.03x). |
| **Кнопка [OK / D-Pad Center]** | Нажатие на выбранную кнопку, сохранение настроек, переключение протокола. |
| **Кнопка [Назад / Back]** | - **Во время трансляции**: приостанавливает видео и открывает диалог настроек сервера.<br/>- **В диалоге настроек**: сохраняет параметры и возвращается в эфир.<br/>- **Двойное нажатие вне воспроизведения**: выход из приложения. |
| **Кнопка [Меню / Настройки]** | Мгновенный вызов окна параметров подключения. |

## 🔍 Диагностика и логирование

Для отслеживания сетевого трафика, процесса буферизации RTSP/HLS и состояний декодера подключитесь к логам устройства:

```bash
adb logcat -s ExoPlayer:V StreamClient:D RtspMediaPeriod:D
```

Пример успешного подключения в логе:
```text
D/StreamClient: Player state transitioned to: BUFFERING
D/StreamClient: Player state transitioned to: READY
I/ExoPlayer: Init ExoPlayer [ExoPlayerLib/1.3.1] [Media3/1.3.1]
```
